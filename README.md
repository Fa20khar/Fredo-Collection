## ✨ Key Features
- **Editorial Fashion Hero**: High-contrast, typography-forward hero with direct collection entry points.
- **Curated Category Grid**: 6 Ladies categories and 6 Gents categories (Unstitched Suits, Dhanak Embroidered, Kurta Shalwar, Waistcoats, Velvet & Pashmina Shawls).
- **Interactive Shop Page**:
  - Live search across products, fabrics, and descriptions.
  - Department filtering (Ladies / Gents / All).
  - Category filtering.
  - Price range slider up to Rs. 6,000.
  - Size and in-stock toggles.
  - Dynamic sorting (Featured, Newest, Price Low to High, Price High to Low).
- **Product Details Page (PDP)**:
  - Multi-image gallery with thumbnail switcher.
  - Sizing selection with validation safeguards.
  - Fabric composition and care instructions.
  - Delivery timelines (3–5 working days).
  - Related outfit recommendations.
- **Frontend Shopping Bag & Wishlist**:
  - LocalStorage persistence across browser refreshes.
  - Slide-out Cart Drawer + dedicated full Cart page.
  - Quantity steppers, removal, and automatic subtotal calculations.
  - Free nationwide shipping progress tracker (free over Rs. 6,000).
- **Seamless WhatsApp Ordering**:
  - Captures customer name, phone number, city, delivery address, and fitting notes.
  - Dynamically creates prefilled click-to-chat order message using international format `923051367640`.
  - Explains the confirmation workflow honestly without pretending to charge real cards.
- **Customer Care & Floating WhatsApp Button**:
  - Accessible floating WhatsApp button with tooltip.
  - FAQs, Shipping, and Return Policy modals.
  - Dual-language support (English & Urdu toggle).

## 🚀 Setup & Development

Install dependencies:
```bash
npm install
```

Start the Vite development server:
```bash
npm run dev
```

Build for production:
```bash
npm run build
```
